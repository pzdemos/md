### 单节点转副本集

==注意:== 如果单节点曾经运行过副本集，如果完全没有运行过副本集，可跳过此步骤，否则迁移新机需要移除原有副本集配置，具体流程如下：
```shell
#  以真正单机模式启动 临时禁用认证（`--auth` 去掉）
mongod --dbpath /mnt/data/mongodb \
       --logpath /mnt/data/mongodb/mongod.log \
       --port 40000 \
       --bind_ip localhost \ #仅在本地操作
       --fork
# 连接并删除 `system.replset 旧副本集配置
mongo --port 40000
use local
db.system.replset.remove({})
# 查询正在运行mongodb进程
ps aux | grep mongod
# 杀死临时禁用认证启动的mongod
sudo kill <单机模式进程号>
```

==注意== ：组成副本集（尤其是多节点）时，**节点之间必须认证**。  MongoDB 使用一个 **keyFile** 来在成员之间共享密钥，本次是在 一个实例上运行两个节点，所以可只创建一个 ，创建如下：
```shell
openssl rand -base64 756 > /mongodb/keyfile 
chmod 400 /mongodb/keyfile
```

#### 多节点运行 
----mongodb 3.6 
``` shell
# 主节点
mongod --dbpath /mnt/data/mongodb \
       --logpath /mnt/data/mongodb/mongod.log \
       --port 40000 \
       --bind_ip 0.0.0.0 \
       --replSet rs0 \
       --keyFile /mongodb/keyfile \
       --auth \
       --wiredTigerCacheSizeGB 2 --fork \
       --fork
# 从节点
mongod --dbpath /mnt/data/mongodb \
       --logpath /mnt/data/mongodb/mongod.log \
       --port 40001 \
       --bind_ip 0.0.0.0 \
       --replSet rs0 \
       --keyFile /mongodb/keyfile \
       --auth \
       --wiredTigerCacheSizeGB 1 --fork \
       --fork

```

==注意== 如果下列运行出现错误(一般新机不会，指从未运行过mongodb) 需要检查 *mongodb-xxxx.sock* 文件，一般在 ==/tmp== 目录下,删除了锁文件后重新启动
```shell
cd /tmp
ls
#删除了对应锁文件
rm -rf mongo-xxx.sock
```
