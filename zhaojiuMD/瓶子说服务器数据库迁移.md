### 单节点转副本集

==注意== ：组成副本集（尤其是多节点）时，**节点之间必须认证**。  MongoDB 使用一个 **keyFile** 来在成员之间共享密钥，本次是在 一个实例上运行两个节点，所以可只创建一个 ，创建如下：
```shell
openssl rand -base64 756 > /mongodb/keyfile 
chmod 400 /mongodb/keyfile
```
创建后需要通过内网传输 ==keyfile== 到隐节点

#### 多节点运行 
----mongodb 3.6 
``` shell
# 主节点
mongod --dbpath /mnt/data/mongodb \
       --logpath /mnt/data/mongodb/mongod.log \
       --port 40000 \
       --bind_ip 0.0.0.0 \
       --replSet rs0 \
       --keyFile /mongodb/keyfile \
       --auth \
       --wiredTigerCacheSizeGB 2 --fork \
       --fork
# 从节点
#==注意==： 从节点需要保持目录干净，否则影响同步
# 确保执行 下列命令 /mnt/data/mongodb 是空的
rm rf /mnt/data2/mongodb/*

mongod --dbpath /mnt/data2/mongodb \
       --logpath /mnt/data2/mongodb/mongod.log \
       --port 40001 \
       --bind_ip 0.0.0.0 \
       --replSet rs0 \
       --keyFile /mongodb/keyfile \
       --auth \
       --wiredTigerCacheSizeGB 1 --fork \
       --fork

```

==注意== 如果下列运行出现错误(一般新机不会，指从未运行过mongodb) 需要检查 *mongodb-xxxx.sock* 文件，一般在 ==/tmp== 目录下,删除了锁文件后重新启动
```shell
cd /tmp
ls
#删除了对应锁文件
rm -rf mongo-xxx.sock
```

#### 配置ossfs

- **配置文件路径**：默认配置文件为`/etc/passwd-ossfs`。
    
- **配置文件格式**：`$bucket_name:$access_key_id:$access_key_secret`。

请执行以下命令，将Bucket和对应的AccessKey信息写入`/etc/passwd-ossfs`中，并将文件权限设置为640，完成默认配置文件创建。

```shell
echo bucket-test-1:AAAI************:AAA8x************************* > /etc/passwd-ossfs

chmod 640 /etc/passwd-ossfs
```

#### 挂载oss

```shell
# 如果没有oss目录需要创建
cd /mnt
mkdir oss

#如果有原来旧挂载且不可用，可卸载
fusermount -u /mnt/oss

# 正式挂载
# knot-chat-cold-storage ==> oss Bucket
# /mnt/oss ==>挂载目录
# sigv4 ==>否使用V4签名 使用OSS V1签名
# region=ap-southeast-7 ==>OSS Bucket请求地域标识符
# url ==> 指定目标Bucket的Endpoint
# rw ===>读写权限
# allow_other ==>允许所有的用户访问挂载目录

ossfs knot-chat-cold-storage /mnt/oss \
  -o sigv4 \
  -o region=ap-southeast-7 \
  -o url=http://oss-ap-southeast-7-internal.aliyuncs.com \
  -o rw \
  -o allow_other
#验证
mount | grep oss

# 挂载成功
>ossfs on /mnt/oss type fuse.ossfs (ro,nosuid,nodev,relatime,user_id=0,group_id=0)

```
