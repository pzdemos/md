#### ==adaReviewV2==

说明：

- adaReviewV2 是一张 ADA V2 审核命中记录表
- 结构在 front/client-v1/server/db/DB.js 里有伪  
    schema：userId、message、createAt、chatCountTalked
- 主要用途是：当 ADA V2 预测命中后，记录该用户在某次 chatCountTalked  
    阶段触发的消息，并统计该用户近期命中次数 countAdaV2

写入点：

- backend/server-v1/server-cluster.pre.js（当前主写入链路；当  
    predictRes.result === 1 时，会往 adaReviewV2 做 updateOne(..., {  
    upsert: true })，并记录 userId + chatCountTalked + message）  
    读取点：
- backend/server-v1/server-cluster.pre.js（同一条主逻辑里会读取  
    adaReviewV2，按 userId 统计近期命中次数，用来计算 countAdaV2，再回写到  
    windowsDB.users.countAdaV2，并驱动后续封禁/机器人测试逻辑）
